# Kelwin × Plurel — brand family source of truth

Kelwin (GTM systems partner & advisory) and Plurel (demand generation & distribution) share TYPE and COLOUR.
They differ in LAYOUT: Kelwin's layout comes from its own original hero (refs/user-kelwin-intent.webp);
Plurel's from refs/user-plurel.webp. When Plurel's system changes, update this file first, then base.css tokens.

## Shared type (Plurel live system, as given by the founder)
- Mona Sans for almost everything; JetBrains Mono in caps only for small Swiss labels (indexes, captions).
- Headlines: width 110%, weight 430, tracking -0.018em. Never bold.
- Accent phrase: weight 300, set apart by colour, never italic. One per headline.
- Body: 400. UI elements: 500 (some 600).
- Small labels above headings: 500, all caps, 11px, widely tracked.
- Sizes: hero & section titles 3–4.5rem (phone) → 5.5–9.5rem (wide). Smaller headings 2–2.6rem.
  Body 15–20px (mostly 15/17), line-height 1.5–1.55, 34–68 characters. Captions/mono 10–14px (mostly 11–13), tracking ≈ .18em.

## Shared colour
Plurel red #BF3A36 (fills whole sections), hover deep red #8E2824, graphite #141517 (dark), paper #FBFAF6 and
ink #110F0A (light), accents blush #F2C9BF, fog #B9BCC2, signal #E8564E. Flat colour only, no gradients. 12-column grid.

## Kelwin-only layout DNA
Full-bleed frosted film hero; left-stacked content (red-square caps label → headline with light final phrase →
short red rule → lede → tracked-caps CTA pair); bottom-right annotation; tracked-caps nav with outlined
"AUDIT REQUEST ↗"; section heads echo the hero. Logo: brand/kelwin-lockup.svg (traced from the founder's master).

## Plurel-only (do not copy into Kelwin)
Split hero (headline left, lede + CTA right), full-width film band beneath the headline, dot-separated
sentence-case nav, sentence-case buttons.
